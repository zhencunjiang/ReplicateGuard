# Security and privacy

## Supported version

Security fixes are applied to the latest published ReplicateGuard release.

## Reporting a concern

Please report suspected vulnerabilities or privacy issues privately to
zhencunjiang@tongji.edu.cn. Include the affected version, platform, impact and
minimal reproduction details. Do not include real participant data or publish
an exploitable report in a GitHub issue before a fix can be evaluated.

## Data-handling boundary

The desktop application and browser audit are designed to process data locally.
They do not require a ReplicateGuard account or upload analysis inputs to a
ReplicateGuard server. Users remain responsible for endpoint security, local
file permissions, backups and compliance with applicable data-governance
requirements. ReplicateGuard is research software and is not a clinical
diagnostic system.
