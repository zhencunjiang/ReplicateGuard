# Changelog

All notable changes to ReplicateGuard are documented here.

## 0.1.0 - 2026-08-09

- Added a local Electron desktop application for Windows x64, Apple Silicon
  macOS and Intel macOS.
- Added streaming unfiltered 10x Matrix Market QC with ambient-profile cell
  calling and expression-derived doublet prioritization.
- Added differential-expression design QC for biological replication, pairing,
  retained QC annotations, confounding, rank, residual degrees of freedom and
  contrast estimability.
- Added browser and dependency-free Python interfaces for metadata auditing.
- Added bundled deterministic test data, an official 10x PBMC 1k public-data
  benchmark, Cell Ranger and emptyDrops call-set comparisons, 43 automated
  tests, packaged-app checks and an editable SVG manuscript figure.
- Added complete installation, validation and reproducibility instructions.
